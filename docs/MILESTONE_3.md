# OpenFantasy — Milestone 3: *Faces of the March*

**Version:** 1.0 · **Date:** 2026-07-08 · **Builds on:** M2 (`6388b00`)

## Theme

M2 gave the world things to do; M3 gives it **fidelity and hands**. The
16-bit look moves from "placeholder pixel art" to genuine FF6-class sprite
craft, every player gets a **face of their own** through a character creator
deep enough to recreate any FF6/FF4-style hero (and infinite originals), and
the world gains survival-sandbox texture — gathering and crafting in the
Terraria/Stardew register, with the JRPG tilt intact.

> Legal line unchanged: we ship zero Square Enix pixels. The creator's parts
> and palettes are original work in the *style* — capable of producing
> lookalikes the way any sufficiently expressive pixel editor is.

## Feature Set

### F1. FF6-fidelity sprite pipeline
- New sprite spec: 16×24 cells, chibi proportions (head ≈ 10 px), 1 px dark
  outline, 3-tone shading ramps per material, hair shine band, 2 px eyes
  with highlight — the anatomy conventions of FF6-era sprites.
- Sprites are **composited at runtime** from grayscale-ramp layers:
  `body` (per skin tone) → `outfit` → `hair` → `hat/accessory`, each layer
  tinted through a 4-color ramp. 3 walk frames × 4 directions per layer.
- Layer sheets are generated by `tools/gen_assets.py` (pure stdlib, as
  before) so the whole look regenerates from code.

### F2. Character creator (menu becomes a creator)
- Options: skin tone (8), hair style (12: bobs, spikes, ponytail, long,
  bandana, braid…), hair color (16 ramps), outfit (10: tunic, cape suit,
  robe, vest+shirt, dress, armor…), outfit primary + secondary colors (16
  each), accessory (none/headband/circlet/feather).
- Live animated preview, **Randomize**, and a **preset gallery** of
  original characters in famous silhouettes (green-haired magitek soldier,
  blond treasure hunter, white-caped general, dragoon in blue…) proving the
  "recreate then vary" promise.
- Appearance is part of the character: sent in Hello, stored in the save,
  broadcast in snapshots so everyone sees everyone's creation.

### F3. Tile fidelity upgrade
- Atlas v2: 3–4 tone ramps, clustered organic noise instead of uniform
  hash speckle, 3 variants per ground material picked deterministically.
- **Edge transitions**: grass→road, grass→sand, sand→water shorelines with
  foam, forest floor darkening — chosen by neighbor mask at render time.
- Water gets sparkle variants; town cobble gets proper brick coursing;
  trees get canopy highlight/shadow structure.

### F4. Gathering (survival-sandbox layer 1)
- **Resource nodes** are entities: Oak (chop), Ore Vein (mine), Berry Bush
  (forage). Placed via a `nodes` list in world.json (region + count +
  respawn, like spawners).
- **Tools** are items with a `tool` field: Axe, Pickaxe, Sickle (Marla
  sells starter tools; better ones craftable). Standing by a node with the
  right tool equipped-or-carried and pressing **E** swings at it (ATB-gated
  like combat); each swing yields materials (wood, stone, iron ore,
  berries) until the node depletes and later respawns.
- No tool = polite refusal message in the FF6 window voice.

### F5. Crafting (survival-sandbox layer 2)
- `recipes.json`: output item + count, input stacks, optional **station**
  (`forge`). Brasshollow gains a forge NPC-less station tile entity.
- Crafting window (**C**): shows recipes, greys out unaffordable ones,
  craft button consumes inputs → produces output. Recipes ship for: Potion
  (berries), Tonic, campfire-roast Berries→Rations (heal food), Iron Bar
  (ore, forge), Iron Blade (bars, forge), Brass Mail (bars+pelts, forge),
  better tools.
- Materials loop closes the economy: gather → craft → equip/sell.

### F6. Protocol v3
- Hello carries appearance blob; snapshot entity records carry appearance
  (players) so late joiners see everyone correctly.
- New `CraftOp` (craft recipe id); nodes ride the existing entity channel.

## Sim Rules
- Appearance is 8 bytes, validated server-side (enum ranges), part of
  CharacterSave and StateHash.
- Nodes: HP, yield table per swing, deplete → hidden until respawn tick
  (same spawner discipline); gathering swings use the world RNG only.
- Recipes validated by DataValidator (items exist, no cycles needed —
  flat recipes, station enum).
