Zero HP is incapacity: the same actor, body, inventory, currency and timing row remain. Incapacitated
actors and bystanders need no decisions. When one living positive side remains, pending choices cancel
and the session holds the outcome with debt and process carry retained. This is not death, corpse/estate
custody, automatic loot/rewards/respawn or safe release to exploration.

## Remaining scope

This is durable physical action integration, not native playable combat or a phase exit. Source
attack/HP consequences now have a concrete binding; the next dependency is legal encounter
entry/staging/release and native controls. Release must preserve positive debt, remaining process
carry, identity/custody and actual support/hazard obligations. It must not simply remove the clock.

Healing, equipment/magic/broader effects, full injury/death/afterlife, rewards, controller handoff,
joining/merging, independent co-op, outside hazards, full dependency closure and production crowd/
latency/scale remain open. The archive reserves complete liquid+pacing+action allowances, but actual
near16MiB reserve exhaustion remains source-reviewed rather than experimentally qualified. The source
duel's independent oracle covers stationary accepted attacks; it is not a second terrain collision
engine or qualification of every invalidation branch. Native controls are compatibility checks,
not battle animation, art, sound, OS/device or human acceptance.

All181 baseline requirements, full UI and campaign/P14 gates remain open. The
[timeless architecture](../../../Runtime/docs/architecture/encounter-actions.md) describes actual owners,
bytes and boundaries; frozen specifications and old evidence remain preserved. Existing ecosystem
authority, temporal, preservation and proportionate-verification doctrine applies without another
process layer. No Fable invocation or unmeasured credit-savings claim accompanies this increment.
