# Delegated archive fixture

The additive Server assembly fixture owns one complete profile40/schema12 journal from its original
fresh RoadThreat genesis. It declares each inherited stat profile's base MaxHp=100000, MaxMp=4096,
and Speed=10000 before admission; attack, magic, defense, growth and heritage remain inherited. Initial
HP/MP equal those profiles' calculated maxima. The second encounter's target is admitted as the second
human before the first transaction. Exact authored progression contributes to admission identity.
This is finite managed endurance calibration, not ordinary cargo balance or native initial preparation.

Every later movement, grant, acceptance, disconnect, recovery checkpoint, expiry, assignment, offer,
withdrawal, encounter choice, bite, retreat sample and archive is a normal authority operation. The
managed host checkpoint supplies the established 30000ms expiry evidence; preparation is not a
measurement of a real socket's initial absence. Offline/unpublished interval semantics belong to the
process/native proofs and inherited recovery law. No pending Care request is used as archive filler.

The same save contains a genuine delegated one-unit source-lot offer withdrawn by that original
delegate. Both terminal command deliveries and witnesses remain nonempty through the coordinated cut
and later revocation. It does not claim a settled gift or currency-priced trade; existing trade tests
remain separate evidence for those cases.

Actual enemy bites fill resource batches253–255. A normally accepted delegated retreat takes a legal
contact-preserving opening before escaping. Its walking obligation crosses the ordinary coordinated
archive policy, then permission revocation, then its final paid sample. Three retained boundary pairs
(`archive`, `revoke`, `resolution`) expose exact before/after database backups, roots and accepted batch
bytes. Expectations come from authority preview with its real historical identity lookup, and are
compared to each actual commit before export. No cutoff threshold or deadline is changed.

The shared API exposes original genesis bytes, source scenario, owner/grantee/opponent/home actors,
paid command/receipt/witness, closed gift commands/outcome, the three boundary records, and clone and
assertion helpers. Backups contain original genesis, recovery tables, complete journal/receipts and
archives. Evidence lives beneath `OPENFANTASY_DELEGATED_RECOVERY_EVIDENCE` when configured, in a unique
fixture directory; otherwise temporary files are removed on fixture disposal.

Three archive tests check exact immutable prefixes and coordinated closing bytes, pure storage reopen,
retained and revoked private-history authorization, permanent participant history, exact original
receipts, full original-genesis replay, duplicate publication refusal, all permanent actor/body/home
bindings, unchanged finite goods/currency/MP, actual HP damage continuity across archived and live
resource histories, and exact route length/readiness/destination costs. No live attachment behavior or
process kill is claimed by these tests; the separate process/native worker owns those proofs against
these same exported boundaries.

No runtime architecture changes: the tests exercise the existing single writer, ordinary archive and
effective-control contracts. No older tests, projects, rules, schemas or specs are edited. Source was
reviewed and whitespace checked by the worker; builds and execution remain integration-lead work.
