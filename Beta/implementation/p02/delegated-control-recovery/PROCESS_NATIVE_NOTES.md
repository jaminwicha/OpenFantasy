# Process and native recovery qualification

The additive process cohort shares one immutable, journaled preparation and clones each exact
boundary into its own evidence directory. Six cases terminate the actual external Host storage
process before and after archive publication, permission revocation, and final paid-retreat
resolution. They use the existing transaction barrier without changing production behavior.
The archive cut must change actual archive bytes. Every reopened result is compared against its
complete recorded old/new root and complete archive rows, including payload bytes, with original
genesis replay, paid receipts, permanent bindings and identity occupancy retained.

`DelegatedRecoveryNativeTests` performs another real after-publication kill, then attaches a live
host to that same recovered database. Pure storage reopen retains the recorded delegated witness;
live attachment releases it through the exact nonadvancing custody event. Attachment preserves
the original episode, permission state, clock, resources and pending paid command. The release
event binds its owner and expected assignment revision; the released witness is checked in the
before-state because Release deliberately has no witness payload.

The returning owner connects through authenticated TLS in an actual background Godot process.
Existing native controls observe Pending, exercise blocked Resume and a held movement key, then
observe the actual host scheduler finish the originally accepted retreat. Restored remains paused
through focus return until explicit native Resume. The held key does not become movement.
Post-draw control captures and ordinary probe responses remain in the rendered-owner directory.
Complete original receipts, resource changes, identities, archive bytes and original-genesis replay
are retained. Actual admitted combat damage is accounted through full actor-revision chains; the
interval is not falsely treated as read-only while paid work continues.

## Exact scope and limits

- Fresh-admission endurance, encounters, initial connection loss, original allowance, delegation,
  closed gift and paid retreat are managed preparation through the real journal. This is not a
  native preparation or wall-clock allowance claim.
- The native continuation uses the existing controlled monotonic host clock to expose the safe
  Pending/Restored transition. It does not alter game rules, accepted costs, archive thresholds,
  simulation step length, or the original deadlines.
- External barrier: 30 seconds; actual kill termination: 5 seconds. Both successful completions
  explicitly check elapsed time. Native journey: 180 seconds including its crash; opening: 30
  seconds; each observation/timer settlement: 5 seconds; mailbox: existing 20 seconds.
- The killed process is the existing Host storage operator. A live listener/socket crash, native
  initial loss, OS device input, human usability and every possible crash-tail ordering remain
  outside this bounded proof. Only the recovered owner is rendered; the shared fixture has two
  admitted humans and preserves the original delegate's permanent bindings and receipts.
- Sources were authored without executing builds or tests in the worker. The integration lead
  owns serialized qualification and its retained pass/failure reports. Source completeness is
  not execution evidence.

## Running and evidence

Filters are the exact classes `DelegatedRecoveryProcessTests` (six cases) and
`DelegatedRecoveryNativeTests` (one case). The lead supplies `OPENFANTASY_DOTNET` and
`OPENFANTASY_DELEGATED_RECOVERY_EVIDENCE`; native additionally requires `OPENFANTASY_GODOT` and
`OPENFANTASY_NATIVE_PLAYER_EVIDENCE`. Process case directories retain genesis, before/expected/
recovered roots, publication batch, barrier response, complete archive rows, stderr and result.
Native retains the actual-crash directory, attached/restored/final roots, exact paid-resource
continuation, rendered observations/images and journey result. No automatic retries are used.

## Native inspection correction

The first native qualification stopped before Godot because the fixture attempted to open the
live database independently while `SqliteWorldAuthority` held its exclusive lease. The retained
failure is `qualification/native-recovery-20261003T150357999636Z/command.log`; this was a fixture
inspection error, not evidence of native behavior or a production lease failure.

Archive and journal inspections now use actual `BackupForHost` snapshots taken before attachment,
after attachment, and after native continuation. Each capture requires the exact observed live
root both before and after backup, and verifies the backup's original genesis, head revision,
advancing-step count and complete canonical state bytes. Only the separate backup receives the
inspection lease; the actual recovered database remains under its one live authority throughout
play. Existing archive-byte, release-event and paid-continuation assertions are unchanged. The
correction adds no retry, timeout, rule change, or second live writer; its execution remains the
integration lead's responsibility.
