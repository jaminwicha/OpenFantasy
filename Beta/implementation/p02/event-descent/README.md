# Event-ordered descent assessment

This increment implements the collision prerequisite for unequal intact trajectories. Its collision
kernel stops bodies at their first supported event, reinserts the stopped material and continues the
remaining falls. The construction adapter applies it to complete retained worlds and reports actual
impact demand. The [architecture reference](../../../Runtime/docs/architecture/event-descent.md) describes
ownership and boundaries.

The existing profile17 excavation authority remains the qualified common-translation resolver. A
read-only candidate does not earn excavation rights, update calendar/custody or install a different
pending-work interpretation. This increment does not claim fracture, injury, debris or live unequal falls.

## Implementation and validation scope

- A finite immutable event cursor with real query counts, first-contact sweeps, exact distance ordering,
  canonical simultaneous stopping sets and stopped-body reinsertion.
- Multiple independent landing distances, a higher body caught by newly stopped material, stacked
  riders, actor blockers, partial ledges and unknown terrain. All scene bodies remain represented.
- Complete-world policy/input pinning; original installed backing, mass, volume, body condition and
  actor custody retained through candidate motion. Complete final contact/load checks remain distinct
  from geometry and from the publishing transaction's eventual ore/time/custody changes.
- Exact rational gravitational energy from actual assembly and body-plus-carried mass; no static
  capacity-to-impact-toughness conversion or invented anatomy-specific damage.
- Every-prefix canonical restoration and dependency/cursor tampering checks. Bounded local Host
  inspection of an exact recorded excavation proposal, preserving its source SQLite bytes.

## Decisions and remaining dependency

The existing structural load planner records failures but does not own fracture or debris. Its transmitted
loads cannot be interpreted as fresh material. Original installed lots remain indivisible production guards;
member shares confer no independently recoverable salvage right. The body schema retains causal injuries
but has no positioned limb colliders or severed-part material owner. These findings make event-ordered intact
collision the next useful prerequisite, with harmful/partial contacts explicitly unresolved.

The geometric query bound includes actual event probes, selected-prefix sweeps and stopping support checks.
Setup, contact discovery, copies, replay and final full-load validation remain unsliced finite work; this
is not a production latency/scale claim. Introducing this cursor into live durable authority requires
versioned policy/bytes, complete result/source/journal reservations and real interruption qualification.
It must not silently change profile17's archived interpretation or work bound.
The larger event bound also cannot be passed blindly into the existing per-terminal-revision identity
reservation scheme. Admission must prove journal/outcome/root capacity for the chosen continuation budget;
tiny slices at the maximum event catalog can exceed the existing retained limits. Those limits stay fixed.

The 2026-09-19 status/next-step review changes the sequence: integrate the qualified intact event
trajectories with the versioned durable owner first, retaining the existing harmless-impact limits.
`ConstructionContactScene` validates a uniform intact pose; the bearing model and physical projection
also bind the original assembly. `VerticalBearing` describes compression transfer, while `BracedFace`
declares rated load transfer without an authored bond-failure law. Neither grants a mechanical bond that
can simply be marked broken. A separate fracture assessment would not remove the pending-work integration
obligation. This ordering brings existing behavior into the real loop before expanding that new domain.

Acceptance for that integration includes a real funded-world interacting trajectory, final load validation
after actual ore/custody/time effects, exact legacy bytes, pre-acceptance capacity proof, interruption/restart
and retry with one original command receipt and time/material publication. Existing bounds remain fixed.
Then implement owned contact response and whole-member joint separation with explicit mechanical semantics
and conserved source-backed located material. This is a sequencing decision, not runtime qualification;
no application or timeless architecture contract changes in this planning update.
Sub-member fragmentation/salvage and harmful actor impacts need explicit material/anatomical contracts.
Wet composition, generated extraction rights, multi-floor rendering, production workloads, devices,
1–4-player timing and the full P00–P14 campaign remain open. No acceptance threshold is lowered.
