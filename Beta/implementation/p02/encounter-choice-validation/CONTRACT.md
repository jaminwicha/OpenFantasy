# Costed native choices and incapacitated outcome

The native encounter checkpoint proves Strike and a winning outcome. This follow-up qualifies the
other actual choice, Wait, and the losing outcome without changing source stats, damage, timing,
authority, storage or saved profile24 semantics. It preserves the broader recovery obligation rather
than describing a safe input lock as finished defeat gameplay.

## Required evidence

Enter the east Bramble Wolf encounter in a separate disposable native world. Deliberately choose Wait
through the actual wheel, keyboard, controller and pointer paths where the unchanged fight permits.
Record the forms actually exercised; death must not be postponed merely to cover another input form.
Wait incurs its actual readiness cost; it does not heal, damage, restore mana or draw combat randomness.
Wolf actions still resolve through source stats and saved random draws while time advances lawfully.

At actual player HP0, retain every resident, body, inventory, wallet, terrain/liquid state and spent
readiness. No ordinary input, repeated Continue, attack or Wait may bypass incapacitation. Menus and
explicit pause remain usable. Close and reopen the exact paused save in a second process with matching
public state and unchanged database bytes. Recorded state and receipts prove costs and causes; a
transient UI view alone does not establish a complete transaction.

Use strict existing success deadlines, retained failure records, disposable no-focus startup settings
and observed native focus. Inspect representative rendered states. Physical devices, production art,
new aftermath rules and full phase acceptance are separate obligations. No automatic retry, edited
resources or hidden direct command submission may make this journey pass.

## Design dependency

The existing profile has no rescue/healing owner and intentionally cannot release an incapacitated
initiator. The [recovery design](RECOVERY_DESIGN.md) identifies the required continuation and proofs.
That document does not make planned recovery executable or weaken any existing gate.
