# Integration and independent review

One native runtime worker owned the 28 Core Geography/Production files. Astra owned tests,
integration, execution, architecture and Git. The runtime was frozen before integration builds.
One independent native critic performed a bounded read-only design scan and coherent source/test
review. No external Claude retry or silent model substitution was dispatched for this increment;
no credit savings are claimed. The critic ran no builds or tests.

The design scan identified complete-owner cuts, distinct delivery cause identity, permanent history
lookup and atomic rollback as the consequential boundaries. Material conservation alone cannot prove
that a previously scheduled stage occurred, and a material cut cannot erase nonmaterial journal facts.
The implementation retains the actual full transport boundary and uses a delivery cause distinct from
the stage. New dependencies pin the complete current transport hash as well as actual opaque evidence.

The frozen-runtime review found no blocking runtime defect. It checked qualified cuts and lower-cut
refusal, callback validation before wrapping and per-stage catches, exact raw/produced head calculations,
all-or-nothing fragments/evidence/identities/throughput, the actual 512-operation envelope, fixed clock
behavior, shared replay partitioning and explicit codec version separation. Review scope includes the
actual construction-completion composition control; its transport is deliberately dry, while separate
tests prove wet split delivery and combined raw/produced water head.

The critic found a meaningful test gap: the original sibling-proof test referenced the original proof
hash in encoded bytes while supplying the sibling proof. That refused at lookup and did not reach the
produced-history comparison. The strengthened test rewrites the encoded proof reference to a genuine
sibling proof whose before/after raw inventory hashes match but preceding Production hash differs.
Production V7 decoding succeeds and reproduces those hostile canonical bytes; explicit authority
validation rejects the exact preceding-owner mismatch. Every nested geography decoder also rejects
with that same underlying cause. The passing focused-03 report executes this distinction. No runtime
change was needed for this review finding.

Astra additionally reviewed the actual source changes, updated seven architecture pages including the
new transport reference, and retained the unchanged WorldSnapshot continued-owner admission guard.
Full world, source effort/issuance, durable retrieval/authentication, native rendering and production
performance remain separate gates. A component dependency captured from a real in-memory owner is
not evidence that a persisted archive can be authenticated and recovered after restart.
