# Native selection adapter scope

The client keeps `IPlayerSession.ReadView()` as the permanent home observation. Selected input starts
at generation zero through `ISelectedPlayerSession`; each presented offer carries the exact port,
home actor, operated actor, generation and control witness. Command principal and session remain the
real authenticated player's delivery. A stale unsubmitted offer is refused; the same submitted offer
retains its original command and receipt task.

The native Characters panel presents explicit, initially unchecked permission scopes for a named
human, incoming acceptance, owner revocation, acquisition, selection, return home and release. The
panel captures the displayed board revision/terms. Controlled presentation uses typed optional facets
directly, with the operated actor as the camera and target origin; it constructs no substitute full
world view. The HUD identifies the home character and continuing human obligations. Every selection
transition clears held input and open reviews and requires deliberate Resume. Focus loss and controller
loss discard the panel's paid review.

The controlled trade path exposes a chosen merchant and explicit quantity for a buy inquiry, then a
separate review of an exact offered quote and a separate confirmation. Confirmation carries the quote,
quantity, price/fees, actor revisions, real delivery and witness captured by that review. Opening,
refreshing and inspecting neither purchases nor retries. A paused character must explicitly Resume.

## Limits and qualification

This is an implementation candidate, not native acceptance evidence. No build, managed test or native
probe was run by the client worker. The new `Client.ActorSelection.FarmSelectedBindingTests` use actual
admitted host ports behind a test-only interface forwarding adapter. They cover capture/identity,
A-to-home-to-A refusal, another client adapter's offer refusal, withheld trade-only facets and exact
paid command preparation. They do not claim TLS, rendered layout, device input or executed paid transfer.

Controlled quick offers cover current combat, retreat, selected recovery/care decisions,
conversation/one applicable quest and a single unambiguous craft recipe. The control panel shows the
permitted pack and current trade. Complete selected material-gift management, production/worksite
selection, private-history browsing, restorative permission UI and selected sell/showing management
remain incomplete; the home screens retain their established binding. Controlled rendering does not
yet reproduce every home canvas decoration, work target or scene-specific camera framing. The new
scene and actual four-human permission/selection/paid journey require rendered and input qualification.
These omissions remain obligations of the full interface contract, not a scope reduction or completed UI claim.
