# HTTP/TLS player host result

Qualified bounded listener/provisioning/process integration on macOS. The reusable net8 Server
adapter owns Kestrel HTTP/TLS requests; the existing net10 dedicated Host composes it with the same
saved authority and player ports. Core, Hosting and Godot do not reference ASP.NET. No new writer,
world clock or IPC layer is introduced.

The dedicated command opens an existing genuine profile35 cargo save, refuses missing/other-profile
worlds, retains actual human controls and NPC merchant policies, provisions bounded private invitations
using the actual validated farm package manifest, and runs TLS/WebSocket admission and gameplay.
It never fallback-creates or upgrades a world. Ctrl+C/POSIX SIGTERM join requests before disposing the
world. Certificate/password paths are local settings; secrets are excluded from diagnostics and URLs.
The operator guide and affected timeless architecture pages describe these bindings and their limits.
