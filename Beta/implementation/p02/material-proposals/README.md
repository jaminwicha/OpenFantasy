# Saved material offers

This increment gives a sender a durable offer that its recipient can inspect and decide later.
Acceptance rechecks actual control, exact stock, body/reach/readiness, both action opportunities
and the complete material/physical consequences. Creation never reserves or moves goods; its
receipt remains the original fact after later acceptance, decline, withdrawal or expiry.

**Integration status:** accepted as a bounded fresh-world local Host feature: 1,941 distinct managed
cases and four actual process kills/recovery pass. See [final checks](qualification/FINAL_CHECKS.json).
Milestone: `codex/milestone-saved-material-proposals-20260929`. No full phase or game gate closes.
