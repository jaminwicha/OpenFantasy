## Qualified behavior

admission includes the complete resident set, actual progression speeds and existing player/NPC

front without inventing an excavation. Initial effort970 makes recovery observable. After35 tactical

## Scope and following work

This is a real durable world/session integration, not a timing-only diagnostic. It is still a Wait-only
coordinated interpretation admitted at fresh genesis. It does not establish playable combat, legal
encounter entry/staging/release, attacks/HP consequences, controller handoff, joining/merging, independent
co-op, outside wet hazards, full dependency closure, crowd continuation, native battle presentation or
production latency/scale. Existing64-resident admission is unchanged; component capacity128 is not a
full crowd fallback. No phase or production gate closes.

The root reserves maximum liquid and pacing payload sizes. The near16MiB reservation boundary remains
source-reviewed, without an experimental maximum-root exhaustion fixture. Journal/identity bounds,
large-world replay/allocation and long-lived storage remain their existing open obligations.

Next implement source-backed action legality, HP/incapacity and effects, then legal encounter lifecycle
and native controls over the same authority. Release must preserve remaining action debt and process
carry and revalidate support/hazards. It must not simply remove timing or resume using tactical tick
count as regrowth/work time. Qualify those interfaces and the full Wait/co-op requirements before any
production combat claim. Full campaign/spec/UI/art/audio/platform requirements remain unchanged.

The [timeless architecture](../../../Runtime/docs/architecture/world-pacing.md) owns the source contracts.
Frozen designs and archives remain preserved; the owner-directed C# decision remains in force. This
increment needs no new ecosystem rule: existing measured-boundary, elapsed-exposure, authority/admission
and proportionate-verification doctrine already applies. No Fable call or credit-savings claim is made.
