# Native terrain breach

The separate `--breach` entry connects earned profile21 extraction to the existing native farm,
public target selection, captured action wheel and actual terrain/liquid rendering. The application
and portable core remain pure C#. No Core law, canonical format, storage schema or authoritative
command interpretation changes. [Terrain/liquid architecture](../../../Runtime/docs/architecture/terrain-liquid-breach.md)
and [native composition](../../../Runtime/docs/architecture/local-watercourse.md#excavation-composition)
describe the persistent interfaces.

## Scope

`user://worlds/wrens-breach.sqlite` has a strict independent profile/world/branch/admission selection.
It preserves the ordinary farm, worksite and watercourse saves. Excavation now has a public worksite
projection independently of physical construction: only owned targets, permitted tool lots, exact
request revisions and known occupancy. Explicit capabilities prevent excavation from implying a
physical member renderer or assisted climbing. Earlier admitted dry excavation profiles retain their
own traversal interpretation.

Ordinary walking reaches the dry bank. Q selects the actual face; V and Right inspect Mine, and Enter
confirms one captured action. Partial labor leaves the divider solid. Final labor removes it, issues
one original substrate unit and allows the existing source-backed liquid law to transfer stock. The
same 6,000 litres remain conserved. The opened target retains its completion blocker. No UI action,
render frame, pause or restart grants stock or work. The legacy starter axe/substrate calibration is
retained; this is not production mining-tool balance.

Liquid rendering owns the combined terrain cutaway; worksite terrain does not draw over it. Ordinary
completed guard sprites remain visible when physical construction is absent. Target cues identify the
actual solid top, then the removed cell's base; the authored bank stance still owns action reach.

## Limits and next dependencies

This is a finite dry-bank excavation/flow connection. It does not close full P01/P02, native OS/physical
controller acceptance, production art/audio or general UI gates. Existing four-sector context wheels,
provisional HUD/terrain/actors and calibrated water art remain limited. The native journey does not
re-prove dialogue Wait or funded NPC construction, nor make those broader systems complete.

Occupied wet space, exposure/displacement, liquid loads and physical gates, reactive fluids/ice/ecology,
coarse/Wait/streaming coupling, scalable material provenance/continuation, and production scale remain
required. The profile21 near16MiB reserve exhaustion threshold remains source-reviewed rather than
empirically exercised; this packet does not change that status. Existing far-bank construction access
limits remain recorded. Full campaign requirements, frozen designs and all prior acceptance thresholds
are preserved.
