# Joined movement prerequisites

`WorldMovementPrerequisites` composes actual spatial reads, current-control rows, carried material,
health/readiness and the exploration clock/hold boundary for one exact movement input. The object
retains selected immutable facts and hashes, not its complete source world. `CanAttempt` and geometry
evaluation describe that captured boundary; freshness checks do not publish an action or bypass
complete-world admission. Current control, spatial and material owners remain authoritative.

`WorldActorCarriage.ValidateCurrent` now compares scope/interpretation, carried custodians and complete
selected counted/transformed lot values. Item/source/output pins, identities, revisions, protection and
reservations participate. Equal amounts alone cannot establish continuity. Structural mass consumers
retain their existing selection rules and installed-backing distinction; no codec or gameplay law changes.

## Joined behavior and ordering

The file-backed case uses actual actor/cargo types and a fresh three-region world. Preparation loads
only two required terrain archives (120 decoded cells) and leaves the third archive unread. The same
actor then crosses cell X=0 to X=-1 through ordinary SQLite authority, retaining its six counted units,
original lot/source identity and earned time. The actual result agrees with prepared geometry, and
reopening replays the complete history from original genesis. This is a **spatial-region crossing**;
it is not a partition-owner transfer, partial-world simulation or process-memory measurement.

Other cases isolate joined dependencies: elapsed time changes without movement or cargo/control
changes; an actual gift changes both sender and recipient carriage; whole-lot gift/return restores the
same identity/quantity/source but advances revision twice; nonadvancing control revocation changes
neither pose, cargo nor calendar; and opening/closing dialogue changes eligibility. Opening dialogue
in the same batch suppresses a geometrically clear movement, while closing the hold earns no time.
Existing actual retreat/care cases additionally cover positive readiness debt, recovery through the
required ordinary exploration steps, incapacity and a pending care request. No clock or dose is invented.

The ordinary processor applies actions and advances time before movement. Selected work or a newly
opened hold can invalidate a previously plausible move; structural admission must use the actual
post-action goods/occupants. The new read object therefore **does not replace that processor or install
its candidate directly**. This ordering remains a required part of the integrated partition design.
