## Findings and corrections

[Source review](SOURCE_REVIEW.json) pins the actual inspected files at `7fbc9ed1` and records six
findings. The decisive distinctions are stable actor/custodian ownership versus spatial membership;
real custody transfer versus walking with unchanged goods; complete access population versus selected
occupancy; earned step order versus wall time; coupled material completion versus work counters; and
a detached dependency context versus an identity index that still retains terrain snapshots.

The access-count finding is a direct bound: `ConstructionProject` allows stored witnesses plus distinct
actor/destination pairs totaling at most32. One witness for each of N distinct actors already costs2N,
so no more than16 can be covered. `ConstructionSnapshot` requires all same-floor actors in the complete
locality. This is a current interpretation constraint, not a newly imposed city or NPC limit. No constant
or refusal is changed. A later protected-access-domain law must retain old historical admission.

The living roadmap/comparison now require both boundary movement and a genuine cross-owner transfer.
Stable owners need not be reassigned whenever an actor walks; the membership index changes instead.
This preserves the original cross-boundary/cargo requirement and strengthens the custody witness.
The contract explicitly forbids closing PLAN-STATE with more isolated geometry helpers, refusal-only
'offscreen' work, storage chunks, hidden complete-world references or deadline changes.
