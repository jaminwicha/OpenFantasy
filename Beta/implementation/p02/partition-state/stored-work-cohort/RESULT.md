counted authority/production/construction owners. Stored qualification reconstructs selected custody
storages/countable lots/policies and the named project/definition from actual owner payloads, with
shared progression/quest/dialogue and command actor/control facts. It uses the same qualification
implementation, including full reserved-stock and required-access checks; no copied work simulation.

ConstructionWorkCohort capture uses complete profile-five admission. It keeps original world/directory
hashes, revisions, required owner descriptors, reservation lot membership and site evidence. It does
not keep complete inventory/production/resident collections, owner bytes, world/scene or terrain.
The site still retains all actor/structure geometry and occupancy witnesses. Capturing the source
performs full encoding/admission work; no full-world capture cost or metadata is claimed eliminated.

Each selected read is bound to its exact captured content hash, role, scope/subject and field shape.
The same strict payload envelope parser serves complete recovery and selected reads. Selected stock
identities must equal the membership established from all holders at capture. The source hash is not
journal authentication: Host capture binds it to an admitted committed directory and the serialized
assessment compares the current directory before any reads. Any changed head, including an unrelated
commit, refuses; there is no implicit witness renewal. Payload/storage failures fence the Host.

Assessment returns only source/command binding, rejection, proposed progress and RequiresCompletion.
It neither advances time/gathering/exposure nor mutates material, reserves identities, issues receipts
or publishes geometry. Final progress may qualify while later identity/capacity/material checks refuse;
RequiresCompletion explicitly marks that larger required cohort. The complete ordinary pipeline
remains the publication path. Current40/41 and other richer sources refuse this legacy capture.
