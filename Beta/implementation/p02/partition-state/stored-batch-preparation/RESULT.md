## Implemented behavior

actual work dependencies plus mandatory timing, gathering and every resident actor image.
`StoredConstructionPreparation` loads that exact set in owner-count slices; each slice and completion
revalidate the admitted directory. Partial loading creates no candidate, time, receipt or progress.
Incomplete preparation cannot complete; a failed read or stale head permanently invalidates it.

Completion evaluates the selected batch in canonical actor order, returns every receipt and advances
passive effects once. The same captured interval can handle an empty selection, held work or a mix of
successful/refused work. Changed project/catalog payloads merge once per owner; later actions see
prior accepted project changes. The old single-action API remains a checked one-receipt wrapper.
`CommitStoredConstructionBatch` uses the existing serialized SQLite publisher and one transaction for
all command rows, identities, owners, directory and any due checkpoint. Original replay remains intact.

Final installation returns the entire unpublished batch to ordinary full admission. A batch crossing
the legacy construction aggregate revision bound does the same, preserving its actual whole-batch
refusal. No per-actor refusal, extra time, work target reduction, limit increase or new historical
interpreter is invented to make multi-actor work pass. No schema/default-world/profile40/41 change.

The Host still drains preparation synchronously under its lock. Slicing counts dependency owners;
it does not bound final CPU time, persist a preparation cursor or schedule a later host tick. The
interval retains complete geometry/directory/identity metadata and reads all resident exposure.

`StoredConstructionWorkOwners` decoded one selected project inside a miniature complete snapshot but
assigned the whole catalog's revision. The existing constructor correctly requires that revision to
equal the sum of all projects' revisions. It therefore rejected multi-project progress.

and canonical bytes, and checks its own revision against the admitted catalog. Complete source admission
