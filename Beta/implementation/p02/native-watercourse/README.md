# Native finite watercourse

The separate `--watercourse` entry connects conserved profile-twenty flow to the inhabited farm,
ordinary walking, finite gathering, Wren's dialogue and funded 200-work construction, and exact save
recovery. The core/application remain C#; no Core law, canonical format or existing world interpretation
changes. [Architecture](../../../Runtime/docs/architecture/local-watercourse.md) defines the interfaces;
[design and discovered limits](DESIGN.md) retain the scope and follow-up obligations.

## What is proved

The fresh content supplies actual terrain walls/floors and one finite 6,000-litre entitlement/lot. Twenty
admitted cells form a stepped channel and pool. Upper water drains and lower water accumulates without
refill. Public geometry excludes source/custody identities; actual cell Z and volume drive presentation.
Native art is a separate editable Aseprite calibration kit, with guarded export and restrained cosmetic
frames. Pauses use the existing selected-clock owners; camera/art cannot change quantities.

## Failures and review disposition

The first build lacked a namespace import; the second hit the xUnit collection assertion analyzer.
Both are retained in `build-initial.log` and `build-second.log`, then fixed without lowering checks.
The first durable journey failed to finish work while the player stayed on the far east bank.
[Diagnostic evidence](diagnostic.log) establishes `AccessLimit`: two current-player routes exhaust the
inherited 256-expansion search, while all authored access routes remain reachable. A real work command
is now tested to reject without consuming inventory, production or labor; the same player walks back
through ordinary movement and the same funded job finishes within the original 256-step work bound.
This is an explicit inherited feasibility limit, not proof of universal construction accessibility.

The first native journey [passed automation](qualification/native-initial.json), but image review found
its inherited two-times camera framing hid the lower pool behind the HUD. Those original images remain.
The separate watercourse view uses integer one-times zoom and a southward offset; the corrected captures
passed the targeted image review. Earlier source critique also found that cutaway earth could make a dry
actor look immersed. Restoring only the proved ground tile beneath that actor resolves the specific cue.
No assertion, deadline, simulation rule or existing acceptance gate was relaxed.

## Remaining full-scope obligations

This is a dry-bank integration with provisional terrain/HUD/actors and calibration surface art. It
provides no swimming, intake, water manipulation, physical shutter, breach, fluid load, reactive second
material, phase change or ecology. Flow fragmentation exhaustion still faults the session safely rather
than providing recoverable continuation. General visibility, stacked-cavern rendering, scale, audio,
Wait/coarse coupling and human/device/art acceptance remain required.

The inherited construction access search needs a scalable, properly scoped proof and visible NPC blocker;
an unknown route must not be mistaken for a physical dead end. No full P00/P01/P02 or production gate
closes here. Frozen specifications, previous milestones and the unrelated predecessor index are preserved.
