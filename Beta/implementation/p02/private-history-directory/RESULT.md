# Authenticated history discovery — bounded qualification

The host now discovers a selected character's terminal paid quotes and material proposals, including
records from previous sessions and archived segments. Fixed 16-entry pages preserve a revision ceiling
and complete sequence/kind/identity cursor; new publications do not shift an ongoing traversal.
Every page requires complete verified history through the actual current head. Corruption after the
requested records/cutoff still refuses disclosure. The directory creates no state owner, index, cache,
schema migration, world step or execution authority.

Home entitlement and exact delegated PrivateHistory remain independent of Trade/Inventory. Open and
due-but-unclosed offers are absent. The directory slot shares identical pending requests, refuses
competing pages, rechecks selection/permission and joins admitted work during both port and host closure.
Selected input/result version2 belongs only to directory retrieval; existing selected wire bytes remain
unchanged. Local and remote application interfaces expose actual observation capture and availability;
remote availability requires its negotiated selected profile and does not imply a current grant.
