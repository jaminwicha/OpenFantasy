# Directory qualification plan

The unchanged gate is authenticated participant disclosure through the real saved world, exact selected
permission and lifetime, complete verified replay, bounded transport and joined admitted work. A page
codec or synthetic list alone cannot prove it. The frozen campaign remains larger than this increment.

| Boundary | Required evidence |
|---|---|
| Directory values | Fixed page bound; distinct typed terminal statuses; copied collection; participant/counterparty identities; total ordering including equal-sequence ties; exact echoed request and next cursor |
| Durable discovery | More than one page of actual published participant records; earlier-session and archived records; no open, due-but-unclosed or foreign records; stable cap after append; complete replay and reopen |
| Integrity | Damage after selected records/cutoff still refuses disclosure and fences the authority; exact live head comparison; no query changes history or time |
| Permission | Home entitlement and PrivateHistory-only delegated access; no Trade/Inventory prerequisite or disclosure; revoked/replaced witnesses, actor/port/generation mismatch refused |
| Lifetime | Identical pending page shares task; different request refuses; queued revocation checked; both port and host shutdown join admitted work |
| Transport | New selected versions while existing request/result bytes stay unchanged; canonical bounds, malformed/tampered request/page/correlation rejected; actual authenticated TLS discovery through the new application API |
| Integration | Warning-free solution and Hosting test builds; explicit affected old selection/query/client/transport cases; independent critic of changed source |
| Preservation | All 821 old test/project/fixture inputs and 23 frozen specification files unchanged; unrelated predecessor index unchanged; before-change ref resolves to original HEAD |

`check.py` serializes commands under the established shared lock, pins actual source/binaries/checker,
retains TRX/logs and failures, rejects empty/skip-only runs, and observes terminal command outcomes.
Builds have the existing 240-second command bound; test selections have 600 seconds. Individual test
and networking deadlines remain unchanged. If a new test/fixture fails, retain its run before repair;
a later pass does not explain a timing failure by itself.

Core authority rules, client scenes, input controls and asset files are unchanged. Do not claim current
Core or rendered regression counts without an explicit dependency comparison or fresh execution.
Native history browsing, full profile40 process-kill/reopen, retained unexplained latency/gift failures,
production-scale performance, physical devices, platform breadth, human/art acceptance and full campaign
remain unqualified by this packet. Full replay per page has a real cost; asynchronous execution does
not make it free or prove latency under load.
