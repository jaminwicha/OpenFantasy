- Explicit profile selectors retain inherited care, outcome, material, excavation, consent and actor
  selection routes. Cancellation may publish between paid samples; Core checks the exact command and
  timing boundary. It never moves the actor, refunds debt or supplies an extra action. An arrived
  actor still makes ordinary choices; autonomous people choose only under their actual controller.
- Home observation8 and selected5 carry own choice/cancellation and complete public same-side status.
  Other actors' command/route data is withheld. Delegated disclosure requires Combat plus Traversal;
  terminal history is withheld from this current-choice view. Exact invitation matching remains.
- Earlier worlds omit the new field, and old encoders reject collective views rather than silently
  discard state. The existing wheel/inspection handles cancellation and explains arrival, incapacity
  and paid costs. End notices distinguish actual reasons and suppress records present at opening.
- Ordinary fresh adventure admission and its seed/name solo opener remain40. The dedicated cargo
  host recognizes a validated41 save; no opener upgrades a world automatically. The explicit copied
  migration API is already available, while its convenient operator/native journey binding remains next.
