# Bounded native review

The existing native geography critic reviewed finite gravity gates, conserved delivery, source lineage,
time ownership, immutable binding, canonical archives, admission and affected documentation. The parent
owned implementation/integration and executed all qualification. An independent native helper mapped
profile integration sites; a bounded worker added host/profile/diagnostic bindings. Neither committed
or ran builds. No Claude/Fable or other external paid-model delegation was used.

Consequential design findings incorporated:

- Preserve forcing intervals separately from explicit arrival; make each funded stage indivisible.
  Never represent partial delivery by reducing effective rainfall and rewriting funding history.
- Use explicitly closed gates, fixed adjacent ports and a sill. Check actual final source lower head
  against receiver upper head, including residual microlitres. Share a gate's allowance across stages.
- Resolve each input basin's own terminal. Keep completion and cancellation distinct; canceling a
  capacity claim alone cannot stand in for a source debit and real receiver credit.
- Do not expose bare physical-state replacement. Public `PlanApply` accepts an exact pinned physical
  plan; internal action rebinding preserves fixed domain/geometry and retained funding/closed history.
- Enforce fresh-root and processed-clock/revision rules in world admission, not only the helper
  factory, because direct snapshot construction and SQLite creation otherwise bypass them.

The parent added mixed-gate failure rollback (including fragment identities) and durable substitutions
of independently valid gate archives with matching stored hashes. All three tamper cases are rejected
by replay. The final focused review checked the transport reference and these tests against the final
APIs and found no consequential mismatch.

This is bounded factual/design review, not external human acceptance, an independent numerical fluid
model, performance qualification or completion of any full campaign gate. Earlier failures remain in
the packet. No thresholds, deadlines or runtime guards were removed to obtain passes.
