# Independent construction material review

**No remaining blocking finding** in the reviewed material accounting and restoration contracts. The content/history reviewer inspected the construction snapshot/project joins, shared material committer, existing production rights validation and ordinary crafting boundary independently of their Core author. [MATERIAL_REVIEW.json](MATERIAL_REVIEW.json) binds 23 exact source, test, oracle and contract inputs. This is a bounded static review, not a second complete planner, migration or codec audit.

Two actionable restoration findings were corrected before final qualification:

- An installed output could previously be represented by a different live lot identity or revision. This did not duplicate material rights, but admitted an unsupported relocation. `ConstructionProject` now requires the original completion-command-derived output lot at revision zero. `ConstructionSnapshot` still requires that exact live output interval, project custody/reservation, completed batch, actor and recipe. A direct regression and malformed wire cases reject replacement IDs and revisions.
- The world advancing-step bound alone did not prove that the builder had experienced the retained work. `ConstructionSnapshot` now sums both work steps and elapsed work per builder using wide integers and checks the resident's actual experienced duration as well as world steps. The regression rejects restored work against the earlier world and against a resident whose experienced time was removed.

The shared committer retires the selected input prefixes exactly once, preserves surviving remainders with advanced revisions, and creates the complete output intervals backed by one retained production batch. Existing validation still rejects overlapping live/retired raw rights, absent or inconsistent source pins, missing output budgets, duplicate output claims, inconsistent lot history and cyclic production lineage. Installed-output reservation is applied only to the declared guard output; the three offcuts remain ordinary unreserved material. No temporary removal of input reservation authorizes the operation.
