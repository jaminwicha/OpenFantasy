# Durable local excavation checkpoint

Qualified 2026-09-19. This increment binds actual actor work, finite source entitlement, retained terrain,
shared material custody and direct support in one durable world action. It is an engine integration
checkpoint; it does not complete general mining, the frontier, collapse/fluid consequences or a phase.

## Implemented scope

Fresh profile ten wraps the actual construction world and a finite extraction catalog. The stable
runtime names remain `OpenFantasy`. Each selected cell retains terrain ancestry and a separately
admitted counted source, exact item/physical calibration, owner, suitable tool pin, work threshold and
adjacent stance. The explicit relation preserves existing incompatible identity-role checks.

`ExcavateIntent` passes through ordinary session/batch admission, sequential world decisions, schema-three
commits, receipts, recovery and recorded history. Players and NPCs use the same rule. Work spends actual
banked effort; the solid cell issues nothing until completion. Completing work publishes its whole-cell
source lot, excavation edit and revisions together. Ordinary crafting and recrafting preserve both the
hole and source retirement. No second authority or IPC layer is introduced.

Access uses the actual actor-to-face ray and unchanged terrain, with horizontal reach, tool ownership,
control, revision and hold checks. Every attempt preflights complete actor/structure direct support and
gathering anchors. Unsafe removal refuses work atomically. Construction and excavation share each
owner's advancing-action and personal-time budget. Same-batch workers cannot both use an old region
revision. Reading holds neither work nor earn effort.

The [timeless reference](../../../Runtime/docs/architecture/excavation.md) describes the exact API,
bytes, rules and boundaries. Related world/material/persistence references were updated with it.

## Review and retained failures

A bounded native critic found three real issues before qualification: per-item physical calibration
needed catalog-wide consistency, actor-to-stance-to-face segments could extend/bend tool reach, and
aggregate work bounds did not enforce each owner's shared construction/excavation opportunities.
All were corrected and regression cases added. The follow-up source/reference review found no further
consequential mismatch; it corrected the documentation to call reach horizontal. Critic review did not
execute tests and does not replace human acceptance.

`test-first.log` retains the expected missing-API failure. `focused-1.log` retains an internal-only actor
fixture helper compiler error; `focused-3.log` retains incorrect fixture constructor arguments and an
xUnit analyzer failure. These test compile errors were corrected. `sequential-workers.log` retains a
failed assertion that confused command-ID receipt ordering with actor-ID execution ordering; the final
assertion maps each receipt to the batch's actual first/second command, requiring first success and
second revision conflict. The original assertion was not weakened into an unordered count. Full
regression verifies the corrected test. The MSB4166 failure remains separately noted above.

## Scope still open

The dry profile excludes reservoir/macro owners; it cannot excavate through an assumed liquid wall.
Containment policy must become explicit retained law in a further composed profile, with real gate
geometry, spill destinations and conserved breached liquid. Direct support refusal is not collapse
simulation or structural strength. Fixed selected-cell ownership does not establish a generated mining
frontier, streaming, extraction catalog expansion, vertical access or migration of lived worlds.

General mining tools/hardness, rubble and variable yields, multi-worker mandates, dynamic hazards,
construction strength, carry-mass balance, excavation controls/animation/audio and production workloads
remain pending. Default farm assets/content and prior world encodings remain unchanged. Full P00/P01/P02
exits, all181 requirements, production platforms/co-op and the campaign through P14 remain open.
