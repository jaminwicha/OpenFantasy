# Retained farm admission

`OpenFantasy.Hosting.Content.FarmWorldAdmission.Create(contentRoot, seedText, playerName)` creates one immutable `WorldSnapshot` candidate from the installed content directory. The directory must contain `packages/`, `legacy/` and `native-farm/`. The function reads content and constructs state; the world service must publish genesis atomically. It never opens a save, replaces a committed world, grants authenticated control or performs offline catch-up. Reopening a world must restore committed bytes rather than call this factory again.

`FarmWorldAdmission.CreateEmbedded(seedText, playerName)` runs the identical factory and validations against readonly resources in the Hosting assembly. Packaged desktop builds therefore need no source checkout, parent directory access, extracted content cache or second copy of the whole source packet in the client. The Hosting project embeds `../../content/**/*` with logical name `OpenFantasy.Content/%(RecursiveDir)%(Filename)%(Extension)` and **`WithCulture=false`**. This explicit metadata matters: source witnesses ending in `.cs.txt` must remain content files rather than be mistaken for Czech satellite resources. The reader normalizes manifest-name path separators for lookup while retaining the actual emitted resource name for stream access. Both modes use the same bounded reader and exact pins.

The selected frozen source package remains unchanged. A separate `content/native-farm/admission-v1.json` records the newly authored embedding and `presentation-v1.json` preserves the exact source appearance references. The original source closure and field mapping continue to describe their original verified, not-yet-playable scope. This narrower admission does not retroactively mark the entire original game or quest imported.

## Bounds and failure behavior

The admission file is bounded to 32,768 bytes; presentation to 16,384; package/closure/record JSON to 65,536; selected presentation witnesses to 65,536. The exact source closure allows at most 64 file entries, 262,144 bytes per file and 1,048,576 bytes in total. Its current 51 entries total **440,303 bytes**. JSON depth is bounded to 32. The fixed admission selects only the 49-record retained packet and exactly four records for this step. Body, language, terrain, spatial and custody constructors additionally enforce their existing value and count limits.

Reads use bounded allocation, exact file consumption and hash checks. Canonical relative paths reject rooted paths, backslash aliases and empty/dot/parent segments. Invalid or changed installed data throws before returning a world. Missing files remain file errors; there is no fallback art, source replacement or partially published state. No file is modified by admission. The installed root is a caller-selected local content directory, not a remote content downloader or authenticated package service.
