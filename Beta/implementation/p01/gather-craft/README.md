# Gathering connected to the native world

9 September 2026. This increment continues the retained farm loop with real source tools, finite resource extraction and persistent regrowth. Crafting, Wren's complete quest/reward progression and a physical windbreak are the next connections. It does not complete P01/P02, the first feedback prototype, or the full 181-requirement campaign.

## Implemented connection

The default farm now has an oak and a berry plant at two explicitly authored, supported positions within their original source spawning areas. The source specifies populations of twelve/eight; these two representative placements do not constitute that complete population generator. Each plant uses its original texture, tool requirement, swing count and renewal delay. Two finite supplied tools join the original eight starting wood. The supplied toolkit is an authored starting condition; the original game did not grant these tools automatically or stock Wren's shop with them.

F/controller Y uses the nearby plant's actual owned tool. Each accepted action pays 400 effort, removes one remaining swing and issues exactly the tool's power in source units into the actor's inventory. The admitted work profile gains ten effort per advancing step, capped at 1,000. This preserves the selected Squire-derived banking behavior; it is explicitly a bounded actor-work profile, not the finished character-stat/class system. Player and NPC commands use the same authority and requirements, although the current autonomous Wren controller still only ambles near home.

The new lot's interval begins at the node's retained issuance cursor. The same transaction advances the cursor, damages the plant, pays effort, changes custody and commits the individual receipt and generated identity. A full pack, missing/reserved/wrong tool, lost manipulation, blocked/out-of-range target, insufficient effort, stale node or historical identity collision cannot consume the resource or pay the action cost. The already selected ordinary world step still contributes its normal clock/effort increment. The predecessor's full-pack partial-yield/damage behavior is explicitly corrected to atomic rejection.

The oak has five swings and the berries four. Their depleted appearances last twenty advancing steps; they then disappear until eligible regrowth at 900/700 steps from depletion. At 20 Hz this is 45/35 active seconds, which maps to 27/21 calendar minutes under the existing forty-minute day. The action-start step is the depletion origin, and that selected advancing step contributes once at its end. Pause, reading holds and offline time do not grant steps or regrowth. The source permits recurring respawn; this adaptation explicitly reserves thirty-two complete cycles per plant. Regrowth restores availability without resetting issued rights or minting inventory. Exhausted reserves remain exhausted until a future admitted ecological renewal mechanism exists.

Resource anchors share the actor's floor and use terrain line-of-sight at its body-center height with the original 448-subunit interaction range. Anchors require supported, clear admitted terrain. These source resource entities remain nonblocking point targets; they are not a new structural tree-collision or forestry simulation.

## Save and presentation boundaries

The shared SQLite schema2 transaction owner now dispatches explicitly versioned world profiles. Existing exploration snapshot/action/step bytes and replay semantics remain retained. A gathering snapshot contains its mandatory work component; movement-only gathering batches also identify profile2. Legacy encoders refuse to drop a new component, and mismatched step profiles reject rather than reinterpret a save. Existing Speak/Give/Close action1 and receipt1 bytes remain valid in a gathering batch; Gather has an explicit action2 encoding.

The new default is `user://worlds/wrens-farm-work.sqlite`, with domain-separated world/actor identities. The original save stays at `user://worlds/wrens-farm.sqlite`, accessible using `--legacy-farm`. This is a distinct new world admission, not a migration of old progress. Both profiles remain supported; no file is reset. Retained tests open an actual previous native save and verify its old head, outcomes and continuation without reconstructing its claimed history using new code.

The renderer receives visible resource positions/phases, the controlled actor's tool lots and effort, and that actor's inventory. Source cursors and future budgets remain private. New source PNGs are copied exactly; the same dimmed original sheet represents the brief depleted interval. The resource names are conveyed by the contextual action rather than overlapping actor sprites. Camera limits and an opaque HUD header keep the farm view and text readable. These corrections do not approve the source art as the production pixel-art target.

G/controller X now transfers up to six wood from one actual lot, including smaller harvested lots. It grants no quest credit. Bulk ingredient/quest consumption must later combine and retire exact intervals atomically rather than assume every gathered unit is already in one six-unit stack.

## Verification and next work

The full Debug and Release runs passed **413 core and 108 hosting cases per configuration**, without skips. Independent Python vectors cover the new gathering component, action2 and step2 bytes, including signed coordinates and exact hashes; C# cases reject every truncated vector. Behavioral tests cover banking, tooling/ownership, NPC equivalence, capacity, holds, contested nodes, old/new profile rejection, geometry, finite exhaustion and historical spawn collisions. Real SQLite tests cover lost replies before/after commit, exact retries, replay and regrowth after recovery. The [final qualification](VALIDATION.json) binds 457 runtime inputs, 17 independent Python fixtures, all host/source checks, the older native farm and lifecycle probes, and the new headless gathering journey. The rendered macOS journey separately passed harvesting, paused depletion, exact cross-process restoration and subsequent regrowth. [Retained captures and reports](qualification/) include the actual saved world; [visual review](VISUAL_REVIEW.md) distinguishes visible berry restoration from the offscreen oak state confirmed by the public report. The Release solution builds with zero warnings/errors; this is not a platform export.

Independent reviews found and closed an insufficient live-cycle reserve, repeated terrain-index construction during v2 encoding, and a client startup ownership leak. The first rendered create stage passed harvesting and pause; its reopen timed out before the resource's due step. Saved data showed only 219 resumed steps, so neither a regrowth failure nor a focus cause was inferred from that timeout. The second instrumented run directly recorded lost focus and the resulting readiness pause. The final test requests actual window focus after interruptions, without bypassing the production pause rule; it passed with one focus request during create and none during reopen. The initial diagnosis remains historical rather than retroactively claiming that its uninstrumented timeout had a proven cause.
