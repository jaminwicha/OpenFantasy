# Beta OpenFantasy implementation decisions

These decisions close the architectural choices left open in the historical readiness register. They are the v1.0 implementation baseline, subject to controlled revision from retained evidence. **Selected** means implement this contract; it does not mean implemented or verified. Numeric pacing and performance envelopes are initial qualification values, not measured release claims. Full requirements remain in [REQUIREMENTS.json](REQUIREMENTS.json); precise behavior is in [TECHNICAL_DESIGN.md](TECHNICAL_DESIGN.md).

| ID | Selected decision | Closure / revisit trigger |
|---|---|---|
| D-01 | Rebuild state ownership in Beta with portable C# authority/Godot adapters; fully import OpenFantasy content and selectively retain verified algorithms | Migration/replay fixtures; do not extend the legacy monolithic world or movement-mode vehicle model |
| D-02 | One process/state owner; portable C# selected after expanded-scope reassessment, with no native kernel or IPC selected | P00–P03 language qualification before broad P04; whole Rust via coarse in-process C ABI remains a valid evidence-triggered alternative, not a second authority; [research](../research-v0_8/csharp-rust-core-reassessment.md) |
| D-03 | Launch Windows/macOS/Linux, 1–4 players; later Android/iOS phase uses same core | P01 executed desktop exports; production matrix and P14 mobile qualification |
| D-04 | Qualify Godot 4.6 .NET stable + .NET 10 LTS; accept exact candidate pins after execution evidence | P00 records editor/SDK/TFM/template/dependency hashes; P01 executes qualification; original 4.4.1/net8 remains untouched |
| D-05 | Integer space/quantities, checked arithmetic, specified modifier ordering/rounding and deterministic counter RNG | Golden vectors across three desktops; version change requires replay/migration review |
| D-06 | 20 Hz target scheduler, durable ingress order, deterministic work budgets | Profile queue/latency; slow rather than omit different NPC work on different hardware |
| D-07 | SQLite single-writer world database; atomic receipt/events/deltas/outbox and durable acknowledgement | Fault injection, backup/migration/recovery tests; no shared live database over network filesystem |
| D-08 | Default hosted world pauses when empty/offline until a gameplay-ready client completes restore; solo/coordinated play shares branch pause | Slow-join fixture; explicit opt-in always-running profile needs offline-care/deadline qualification |
| D-09 | Full required-decision Wait in bounded same-field encounters, with seamless staged transitions | Native visual acceptance plus authoritative two-client transition tests |
| D-10 | Independent co-op uses disclosed local stasis and outside opportunity cost; no retrospective aging/damage/work | Verify long holds, retained effects, dependants and fixed-date notifications |
| D-11 | Duration deadlines have one named anchor and suspension ledger; shared appointments default to fixed world dates | Repeated entry/exit, mixed-clock attendees, notices and recurring-obligation regression |
| D-12 | All consequential outside influence requires revalidated admission; whole vehicles/supports share timing | Over-budget closure uses recorded shared pause with complete deterministic sequential processing; no participant truncation |
| D-13 | No connected-player decision timer; recorded disconnect → 30-second allowance → authorized controller/NPC handoff | Reconnect and idle-host controls; no hidden wall-clock replay dependency |
| D-14 | All NPCs share applicable player state/actions; bounded cognition uses scoped knowledge | Actor parity, offscreen history and blocked-plan tests; no depth reduction as optimization |
| D-15 | Finite realized world with practically unbounded frontier; stable macro borders, versions and mutations | Exploration-order, source-history and identity/resource conservation tests |
| D-16 | Sparse discrete 3D terrain, initial 32×32×16-cell chunks, integer shape volumes, local rebased rendering and parent-local vehicle frames; realm distinct from Z | P02 true mutable floors/subfloors, collision/traversal/support; rendering cannot choose authoritative topology |
| D-17 | Shared typed process/effect language for craft, research, magic, classes, enchantments and maintenance | Bounded graphs, ownership/cost/stacking tests; auto-selection protects equipped/favorited/heirloom/reserved lots with durable preferences and authorized previewed overrides |
| D-18 | Vehicles are persistent assemblies; mounts/pets/familiars are living actors with real care/custody | Fit/repair/tow/feed/dismiss/recall/restart tests across all required travel families |
| D-19 | Species history, culture, individual agency, religion and deities remain distinct causal state | Exceptional births, changed worship, divine intervention and epoch restore cases |
| D-20 | Multiple grand arcs, adventurelets/decks and autonomous outcomes share real entities/resources | NPC resolution, competing arcs, stale eligibility and missing-participant tests |
| D-21 | Any canonical past instant/address is accessible through preserved lived history or deterministic ancient-history refinement; preparation pins head revision/same-instant commit boundary | P03 unprepared-date/order/restart and same-instant proof; P10 chronology/archive qualification; checkpoints accelerate, edits fork immutable prepared prefixes |
| D-22 | Packages are namespaced/versioned typed extensions; unrestricted executable mods are not the default | Real extension + upgrade/removal/migration fixture before content scale |
| D-23 | AI is optional, scoped, validated and recorded; provider-independent replay/fallback | Provider unavailable and malicious/invalid proposal tests |
| D-24 | Presentation follows semantic authority; dedicated artist and critic roles, interchangeable Codex/Claude leads | Native art/animation acceptance, independent review and human playtests |
| D-25 | Initial measured-workload target: 10,000 realized actors, 512 detailed pooled actors, four progressing branches | Hardware qualification before release claims; retain additional saved state, revise explicitly if needed |
| D-26 | Initial full day/night cycle is 2,400 authoritative exploration seconds, about 40 uninterrupted real minutes | P02/P04 human pace acceptance; holds exclude wall time; rates remain versioned tuning |
| D-27 | Rest earns interval-based partial recovery; camp duties, care, watches and events use real actors/resources | Acceleration needs affected-player consent; isolated no-companion/refused-acceleration case must pass P03/P04 UX qualification; no reset loops or instant-rest clock |
| D-28 | Mining/construction/tunneling share conserved material jobs, rated structural support and finite-volume fluid dependencies | P02 mutable stacked terrain; P03 concurrent edits, recovery and cross-chunk support/fluid invalidation before broad expansion |
| D-29 | Fortress building, ore/alloys/smithing, farming/foraging, teas/springs and enchantments use shared production, actors, heat and effects | Ordinary field/management parity, quantity/provenance conservation and no recovery reset shortcuts |
| D-30 | Gradual wear/exposure and discrete damage both change persistent material condition through distinct accountable contributions | Event retries plus split/batched exposure; support and rendering follow committed state without double debit |
| D-31 | Birth, development, care, kinship, partnership and death preserve identity and use declared exposure/consent policies | P01 schema, P03 real birth/maturation/death/custody/office fixtures, P08 full lifecycle across Wait and distant simulation |
| D-32 | Estates/succession use actual property; mandates identify actor versus continuing office/institution principals and explicit survival rules | Death revocation versus valid continuing work, inheritance disputes, regency, stale orders; resurrection cannot undo distributed consequences |
| D-33 | Simple JRPG views progressively reveal earned rule/property/recipe/forecast detail through scoped knowledge | Same commands/authority across detail levels; no secret/debug leakage or compulsory expert micromanagement |
| D-34 | NPC desires/preferences influence feasible belief-based plans; experience changes recorded motives | Different priorities from equivalent facts, no omniscient utility scoring or compulsory narrative behavior |
| D-35 | Dream realms are seeded scoped sessions tethered to the same real actor/body and exposure clock | P03 real tether/interruption; P10 depth; no cloned inventory, symbolic material export, secret-truth query or free healing/teleport |
| D-36 | Local markets price real stock/demand through bounded rules; quotes have revisions, quantity limits, fees and expiry; caravans/guards perform real service | P03 two-market quote/cargo/retry proof, P07 trade/escort breadth; conserved custody and earned market knowledge |
| D-37 | Sites/buildings, ownership, jurisdiction claims, recognition and effective political control remain distinct shared-world records | Castle/town/crypt/dungeon-to-polity growth uses actual actors, resources, mandates and diplomacy; no automatic sovereignty flag |
| D-38 | Alignment axes, personal values, reputation and cosmic obligations are distinct evidence-driven state | Rules permit change and individual exceptions; no species-determined fate or omniscient moral inspection |
| D-39 | Historical archives retain all information needed for arbitrary past reconstruction, with versioned interpreters and shared immutable branch prefixes | Lossless compaction, old-version reconstruction, storage growth and progressive preparation; no silent era rounding or chronology deletion |
| D-40 | Real-time exploration puzzles use fixed-step shared movement/triggers and persistent objects; entering Wait couples their hazards | Combined skill/item/element/party solutions, readable windows and accessible alternatives; no second physics clock |
| D-41 | Shared action definitions support broad skill families, explicitly fishing/hunting/cooking/knitting/writing/acting/acrobatics | Real prerequisites, time/resources, progression, outcomes and performance hooks for player/NPC parity; labels alone do not complete content |
| D-42 | Cities contain full-depth residents/travelers and real merchant cargo over shared surface/underground/realm topology | Candidate 20,000-resident full-city qualification is separate from the early 10,000-actor benchmark; measure before support claims |
| D-43 | Composite challenge assessment uses capabilities, knowledge, tools, resources, team, time/environment and realm access | Suggested scalar tiers cannot substitute for feasible action chains or expose hidden facts |
| D-44 | Procedural progression retains versioned, seeded witnesses with dated assumptions; world events revalidate them | P03 combined time/capability/realm proof; natural alternatives/failure and recurring windows without fabricated victory, forced reset or universal deadline |
| D-45 | Persistent anatomy injuries affect senses/grip/actions/equipment; scars and functional loss are distinct, with serious loss rare | Custody and save/clock/branch proofs; ordinary rest cannot regrow anatomy, but valid defined restoration spells reliably repair their declared losses |

## Remaining gates, not unresolved architecture

| Gate | Must be closed before | Required artifact |
|---|---|---|
| Q-01 Toolchain and export pairing | P01 completion, with candidate pins in P00 | Exact compatible pins, executed Windows/macOS/Linux client and host fixtures |
| Q-02 Hardware/OS floors and workload envelope | Broad production commitment and release support claims | Named machines/OS versions, replay equality, CPU/RAM/save/network measurements |
| Q-03 Native visual scale/body/action coverage | Bulk art/animation | GDD art matrix plus owner-accepted motion, editable exports and measured second-kit throughput |
| Q-04 Clock/transaction/branch correctness | Expansion beyond the retained foundational slices | Executed long-Wait, admission, retry/crash, origin-claim and branch-isolation evidence |
| Q-05 Semantic no-loss assimilation | Content production completion | Complete source-to-target ledger, original-route fixtures, live-world continuations and durable import evidence |
| Q-06 Enjoyment, readability and scope throughput | Production scaling and release candidate | Human/virtual playtests distinguished, second-region production evidence, full requirement coverage |
| Q-07 Core language qualification | Broad P04 production, with fixtures/hardware recorded P00 and evidence P01–P03 | Retained LANG-01–04 workloads, tail latency/GC/RAM/archive growth and export/replay/crash results; choose a whole Rust core or isolated kernel only on demonstrated need and integration evidence, otherwise close on C# |

Balance values and cosmetic timings can be tuned within these contracts. A change to authority, arithmetic, clock ownership, material provenance, actor parity or temporal semantics is architectural: record the reason, affected requirements, migration/replay impact and retained tests before adoption. Previous GDD/specification editions remain archived; this baseline never authorizes deleting their history.
