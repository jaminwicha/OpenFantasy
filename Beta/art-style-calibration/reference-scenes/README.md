# OpenFantasy reference scenes — first set

Five original-content studies using the owner-endorsed restrained v06 visual direction. These are reference illustrations for style and world presentation, not a runnable scene pack or validated sprite/animation set.

Each scene draws on actual OpenFantasy content and assets. Weather, architecture and action staging elaborate that source for Beta; the per-scene records distinguish those interpretations. Earlier calibration versions are preserved.

## Owner feedback

All five examples are positively received, with a request for less conspicuous repeated sprite use. Preserve the visual style and improve authored variation within/across scenes. Living personality, emotion and interaction must also be demonstrated in the subsequent animation pipeline.

## Generation and review

Generated with the built-in image generation tool. All five images were saved in this project and visually inspected. The index verifies source content IDs and records output hashes; individual records preserve prompts, input images, original asset references and generation provenance. Source identity and visual coherence were reviewed; pixel-grid, animation, dynamic weather and engine behavior were not established by these stills.
