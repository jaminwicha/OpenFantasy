# OpenFantasy documentation

The [architecture reference](architecture/README.md) explains the game's boundaries, state ownership,
data flow and invariants. It is organized by subject and describes contracts independently of the
implementation schedule.

[Build and run instructions](../README.md) describe development tools and controls.
[The implementation handoff](../../implementation/AGENT_HANDOFF.md) records progress, evidence and
open acceptance gates. The [preserved design baseline](../../spec-v1_1/TECHNICAL_DESIGN.md) retains
the reviewed specification. These documents serve different purposes; none replaces the others.
