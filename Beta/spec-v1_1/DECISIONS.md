# Beta implementation decisions

These decisions close the architectural choices left open in the historical readiness register. They are the v1.1 implementation baseline, subject to controlled revision from retained evidence. **Selected** means implement this contract; it does not mean implemented or verified. Numeric pacing and performance envelopes are initial qualification values, not measured release claims. Full requirements remain in [REQUIREMENTS.json](REQUIREMENTS.json); precise behavior is in [TECHNICAL_DESIGN.md](TECHNICAL_DESIGN.md).

| ID | Selected decision | Closure / revisit trigger |
|---|---|---|
| D-01 | Rebuild state ownership in Beta with portable C# authority/Godot adapters; fully import Alpha OpenFantasy content and selectively retain verified algorithms | Migration/replay fixtures; do not extend the legacy monolithic world or movement-mode vehicle model |
| D-02 | One process/state owner; portable C# selected after expanded-scope reassessment, with no native kernel or IPC selected | P00–P03 language qualification before broad P04; whole Rust via coarse in-process C ABI remains a valid evidence-triggered alternative, not a second authority; [research](../research-v0_8/csharp-rust-core-reassessment.md) |
| D-03 | Launch Windows/macOS/Linux, 1–4 players; later Android/iOS phase uses same core | P01 executed desktop exports; production matrix and P14 mobile qualification |
| D-04 | Qualify Godot 4.6 .NET stable + .NET 10 LTS; accept exact candidate pins after execution evidence | P00 records editor/SDK/TFM/bundled-runtime/template/RID/dependency hashes separately; SDK10 installation does not imply net10 client targeting; P01 executes qualification; original 4.4.1/net8 remains untouched |
| D-05 | Integer space/quantities, checked arithmetic, specified modifier ordering/rounding and deterministic counter RNG | Golden vectors across three desktops; version change requires replay/migration review |
| D-06 | 20 Hz target scheduler, durable ingress order, deterministic work budgets | Profile queue/latency; slow rather than omit different NPC work on different hardware |
| D-07 | SQLite single-writer world database; atomic receipt/events/deltas/outbox and durable acknowledgement | Fault injection, backup/migration/recovery tests; no shared live database over network filesystem |

| D-14 | All NPCs share applicable player state/actions; bounded cognition uses scoped knowledge | Actor parity, offscreen history and blocked-plan tests; no depth reduction as optimization |
| D-15 | Finite realized world with practically unbounded frontier; stable macro borders, versions and mutations | Exploration-order, source-history and identity/resource conservation tests |

| D-21 | Any canonical past instant/address is accessible through preserved lived history or deterministic ancient-history refinement; preparation pins head revision/same-instant commit boundary | P03 unprepared-date/order/restart and same-instant proof; P10 chronology/archive qualification; checkpoints accelerate, edits fork immutable prepared prefixes |
| D-22 | Packages are namespaced/versioned typed extensions; unrestricted executable mods are not the default | Real extension + upgrade/removal/migration fixture before content scale |
| D-23 | AI is optional, scoped, validated and recorded; provider-independent replay/fallback | Provider unavailable and malicious/invalid proposal tests |

| D-34 | NPC desires/preferences influence feasible belief-based plans; experience changes recorded motives | Different priorities from equivalent facts, no omniscient utility scoring or compulsory narrative behavior |
| D-35 | Dream realms are seeded scoped sessions tethered to the same real actor/body and exposure clock | P03 real tether/interruption; P10 depth; no cloned inventory, symbolic material export, secret-truth query or free healing/teleport |
| D-36 | Local markets price real stock/demand through bounded rules; quotes have revisions, quantity limits, fees and expiry; caravans/guards perform real service | P03 two-market quote/cargo/retry proof, P07 trade/escort breadth; conserved custody and earned market knowledge |
| D-37 | Sites/buildings, ownership, jurisdiction claims, recognition and effective political control remain distinct shared-world records | Castle/town/crypt/dungeon-to-polity growth uses actual actors, resources, mandates and diplomacy; no automatic sovereignty flag |
| D-38 | Alignment axes, personal values, reputation and cosmic obligations are distinct evidence-driven state | Rules permit change and individual exceptions; no species-determined fate or omniscient moral inspection |
| D-39 | Historical archives retain all information needed for arbitrary past reconstruction, with versioned interpreters and shared immutable branch prefixes | Lossless compaction, old-version reconstruction, storage growth and progressive preparation; no silent era rounding or chronology deletion |
| D-40 | Real-time exploration puzzles use fixed-step shared movement/triggers and persistent objects; entering Wait couples their hazards | Combined skill/item/element/party solutions, readable windows and accessible alternatives; no second physics clock |
| D-41 | Shared action definitions support broad skill families, explicitly fishing/hunting/cooking/knitting/writing/acting/acrobatics | Real prerequisites, time/resources, progression, outcomes and performance hooks for player/NPC parity; labels alone do not complete content |
| D-42 | Cities contain full-depth residents/travelers and real merchant cargo over shared surface/underground/realm topology | Candidate 20,000-resident full-city qualification is separate from the early 10,000-actor benchmark; measure before support claims |
| D-43 | Composite challenge assessment uses capabilities, knowledge, tools, resources, team, time/environment and realm access | Suggested scalar tiers cannot substitute for feasible action chains or expose hidden facts |
| D-44 | Procedural progression retains versioned, seeded witnesses with dated assumptions; world events revalidate them | P03 combined time/capability/realm proof; natural alternatives/failure and recurring windows without fabricated victory, forced reset or universal deadline |
| D-45 | Persistent anatomy injuries affect senses/grip/actions/equipment; scars and functional loss are distinct, with serious loss rare | Custody and save/clock/branch proofs; ordinary rest cannot regrow anatomy, but valid defined restoration spells reliably repair their declared losses |
| D-46 | Geography evolves through versioned geological/climatic/hydrological processes above mutable local terrain; the default frontier is planar and practically unbounded | Finite outlet witnesses, shared macro edges and bounded acyclic preparation or explicit closed reservoir components; no infinite/global solve or implicit spherical planet |

| D-50 | Seasonal plants/cohorts, food webs, migration and dispersal use actual resources and shared creature action rules; biome labels derive from state | Phenology, growth/harvest, neutral/conditional hostility, prey/resource contention, cohort promotion and distant parity; no discovery-time refill or instant mature forest |

| D-52 | Underwater and underdark regions are actual elevation/terrain habitats with water/air/heat/capability and settlement continuity | Cavities versus aquifers, safe traversal/Wait, historical submerged sites, inhabitants/resources and distinct optional planar portals |

Balance values and cosmetic timings can be tuned within these contracts. A change to authority, arithmetic, clock ownership, material provenance, actor parity or temporal semantics is architectural: record the reason, affected requirements, migration/replay impact and retained tests before adoption. Previous GDD/specification editions remain archived; this baseline never authorizes deleting their history.
